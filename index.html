扭轉紙環剪開實驗室

紙條先扭 n 個半圈、再黏成環，接著畫上等分線把寬度分成 k 等分（k = 1 就是不剪），再沿線剪開。剪完後每個獨立的環會塗上不同顏色；拉動「拉開檢視」可以把環往外拉：沒套住的環能完全分開，套住的環會像鍊子一樣被拉到繃緊，解不開時就停下來。點下方的色塊，則能只看單一個環。

全覽：n 個半圈 × 分成 k 等分

每格寫出剪完的結果，L 是原本紙條的長度。紅框代表結果會打結（n 為奇數且 n ≥ 3）。每格最下面標出剪出來的環能不能分開：只有完全不扭（n = 0）時能分開，只要有扭轉，剪出來的環一定互相套住。點任一格，就會在上方 3D 圖重現。

歸納出的規律

  1. n 為偶數（雙面）：分成 k 等分剪開，就得到 k 個等長（L）的環。每個環各扭 n 個半圈，任兩個環互相纏繞 n/2 次。
  2. n 為奇數、k 為偶數：得到 k/2 個環，每個長 2L，都打成 (2, n) 環面結（n=1 不打結，n=3 是三葉結，n=5 是五葉結）。
  3. n 為奇數、k 為奇數：中間那條仍是長 L、扭 n 個半圈的單面帶，另外 (k−1)/2 個環長 2L。所有環彼此纏繞。
  4. 剪幾刀？n 為奇數時，偏離中線的一刀會繞兩圈才回到起點，同時剪開對稱的另一條線，所以實際刀數比 k−1 少。
  5. 一般定理（Godzik 等人）：把 k 條帶子的中心線合起來看，若 n·k 為偶數，就是環面鏈 T(nk/2, k)；若 n·k 為奇數，則是 T(n(k−1)/2, k−1) 再加上一條核心圓。

本頁的「邊緣環繞數 Lk」和「環與環纏繞次數」都是用高斯連結積分從 3D 模型即時算出來的，不是查表。帶子沒打結時，扭轉半圈數等於 2×Lk；帶子打結時，壓平後數到的半圈數還要算進結本身的扭曲（寫成 Lk = Tw + Wr，即 Călugăreanu 定理），所以前人科展報告裡的「扭轉數」會因壓平方式不同而有差異。
