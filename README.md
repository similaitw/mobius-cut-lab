# 扭轉紙環剪開實驗室

一個互動網頁：把紙條扭 n 個半圈、黏成環，再把寬度分成 k 等分剪開，看看會得到什麼。

線上版：https://mobius-cut-lab-one.vercel.app

## 功能

- **3D 實驗室**：調整扭轉半圈數 n（0～9）與等分數 k（1～6，k = 1 為不剪），看剪刀沿等分線前進的動畫。
- **即時計算**：用高斯連結積分算出每個環的長度、邊緣環繞數 Lk、是否打結，以及環與環之間的纏繞次數。
- **拉開檢視**：以物理模擬把剪出的環往外拉；沒套住的環可完全分開，套住的環會拉到繃緊、解不開時停下。
- **預測模式**：先猜再揭曉，適合課堂使用。
- **全覽表**：n × k 所有組合的結果與能否分開。
- **方向一手冊**（`guide.html`）：用環繞數定義扭轉數的六個步驟、平放版 Lk = Tw + Wr 的證明、實驗步驟與預測表，圖中交叉點由程式自動計算。
- **前人研究整理**：台灣與日本的科展作品、數學論文，以及還有空間的研究方向與對策。

## 技術

單一 `index.html`，使用 [three.js](https://threejs.org/) r128（由 jsDelivr CDN 載入），不需要建置步驟。
